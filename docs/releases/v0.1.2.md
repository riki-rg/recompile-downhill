# Downhill Native v0.1.2 — Stage 01 ISO Explorer

## Summary

`v0.1.2` delivers the first native ISO Explorer milestone for the project’s single target: **Downhill Domination USA / NTSC-U**. It improves the prior signature-only proof of concept into a bounded, native ISO-9660 metadata reader.

## Included

- Read-only ISO selection through Android Storage Access Framework.
- Java-to-C++ JNI bridge using `ParcelFileDescriptor`.
- C++20 ISO-9660 validation at the Primary Volume Descriptor.
- Root-directory inspection with strict bounds checks.
- Volume identifier plus up to 32 root entry names/sizes shown in the application.
- Build coverage for ARM64, ARMv7, x86, and x86_64.
- Updated README, changelog, stage documentation, and implementation roadmap.

## Important limitations

This is a foundation release, not a playable port:

- It does **not** run or emulate PS2 code.
- It does **not** yet confirm an ISO is Downhill Domination USA.
- It does **not** extract, copy, cache, or redistribute game data.
- It supports current-stage ISO-9660 root metadata only.

## Verification

The release APK is built from tag `v0.1.2` after successful execution of:

```bash
./gradlew testDebugUnitTest assembleDebug --no-daemon
```

## Data policy

The APK contains original application code only. Users must select their own legally dumped disc image locally. Never submit commercial game content, ISO files, BIOS files, or extracted assets to this repository.

## Next milestone

Stage 02 will introduce a strict, metadata-only compatibility gate for a supported Downhill Domination USA layout. It will report supported build, unsupported revision, or non-target image before any game-specific runtime work proceeds.
