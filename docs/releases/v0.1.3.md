# Downhill Native v0.1.3 — Stage 03 Native Runtime Diagnostic

## Summary

`v0.1.3` adds the native Android rendering and input diagnostic foundation for the project’s exclusive target, **Downhill Domination USA / NTSC-U**. This release does not include commercial game content and is not a playable game port.

## Included

- Dedicated landscape diagnostic activity using OpenGL ES 3.0.
- C++20/Android NDK render path connected through JNI.
- Original schematic downhill test scene made entirely from procedural color panels.
- Lifecycle-aware `GLSurfaceView` setup, including pause/resume handling and requested EGL context preservation.
- FPS telemetry plus normalized steering, throttle, and brake state.
- Touch mapping: left/right steering, upper-right throttle, lower-right brake.
- Android gamepad diagnostics: left stick/D-pad steering, left/right triggers, and common face/shoulder buttons.

## Verification

Built from the `v0.1.3` source tag only after:

```bash
./gradlew testDebugUnitTest assembleDebug --no-daemon
```

The release artifact includes native libraries compiled for ARM64, ARMv7, x86, and x86_64.

## Important limitations

- Not a playable game and not PS2 emulation.
- No MIPS/VU executable loading, BIOS, ISO extraction, audio, physics, camera, collision, or Downhill game assets.
- No compatibility verdict for a Downhill Domination USA dump yet; the metadata-only fingerprint gate remains a separate next step.
- The diagnostic scene only proves the renderer/input path on the device where it is tested.

## Data policy

The APK contains original code and generated diagnostic visuals only. User-owned ISO images remain outside app storage and must never be committed, attached to releases, or submitted to the repository.
