# Downhill Native v0.1.4 — Stage 02 USA Fingerprint Gate

## Summary

`v0.1.4` introduces the first Downhill Domination USA / NTSC-U fingerprint verdict for user-selected ISO images. It is deliberately conservative: it reads only boot-configuration metadata from the user's own file and reports a classification, not a playability approval.

## Included

- Native read-only lookup of the root `SYSTEM.CNF` record (bounded to 16 KiB).
- Conservative compatibility verdicts:
  - `UNSUPPORTED_LAYOUT` — no readable `SYSTEM.CNF` metadata;
  - `NON_TARGET_PS2_DISC` — boot record does not advertise the target serial;
  - `USA_CANDIDATE` — boot record advertises `SLUS_206.47`, the documented Downhill Domination NTSC-U serial.
- Updated ISO Explorer report combining volume metadata, root entries, and the verdict.
- Stage 02 documentation defining the evidence contract and the path to a full supported-build manifest.

## Verification

- APK built from the `v0.1.4` source tag after `testDebugUnitTest` and `assembleDebug` succeeded.
- Native fingerprint code compiles for ARM64, ARMv7, x86, and x86_64.

## Important limitations

- A `USA_CANDIDATE` verdict is not a supported-build approval; archive layout verification remains pending.
- No PS2 code execution, emulation, asset extraction, or gameplay is included.
- No proprietary data is bundled, cached, uploaded, or redistributed.

## Data policy

Users select their own lawfully dumped disc image locally. Never attach ISO, BIOS, executable, or extracted assets to issues, pull requests, or releases.
