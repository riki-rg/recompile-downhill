# Downhill Native v0.1.5 — Stage 04 Recursive ISO Index

## Summary

`v0.1.5` upgrades the ISO Explorer to a bounded recursive directory-tree index with aggregated image statistics. This is structural groundwork for future Downhill-specific archive adapters and reads only directory metadata — never file payloads.

## Included

- Reusable, bounds-checked ISO-9660 directory-record parser in the C++20/NDK runtime.
- Recursive tree index with explicit safety caps:
  - depth 4;
  - 512 indexed entries;
  - 96 displayed lines;
  - 1 MiB maximum single-directory read.
- Image statistics: indexed files, directories, payload bytes, and largest indexed file.
- ISO Explorer report now shows the recursive tree, statistics, then the Stage 02 compatibility verdict.

## Verification

- APK built from the `v0.1.5` source tag after `testDebugUnitTest` and `assembleDebug` succeeded.
- Native code compiled for `arm64-v8a`, `armeabi-v7a`, `x86`, and `x86_64`.

## Important limitations

- Statistics cover only entries within the safety caps; they are diagnostic, not a byte-exact audit.
- No archive extraction, caching, or export of file contents.
- Compatibility verdict semantics unchanged: `USA_CANDIDATE` is not a supported-build approval.

## Data policy

Only directory metadata and the bounded `SYSTEM.CNF` boot record are read from the user's own ISO. No proprietary data is bundled, cached, uploaded, or redistributed.
